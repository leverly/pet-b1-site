⑂ 条件句与虚拟

if 从句的"主将从现"是第一大坑，第二条件句的 were 是第二大坑。

去练语法真题 →
01 第一条件句（真实条件）B1 核心 if + 一般现在时, 主句 will/can/must + 动词原形。条件很可能实现。 2 条避坑 · 3 题

if + 一般现在时, 主句 will/can/must + 动词原形。条件很可能实现。

If + 现在时, 主句 + will + V
  • If it rains, we will stay at home.如果下雨，我们就待在家里。
  • If you study hard, you will pass.如果你努力学习，就会通过。
if 从句用将来时（第一大坑）
If it will rain, we will stay at home. If it rains, we will stay at home.
if 引导的条件从句中"主将从现"：主句将来时，从句用现在时。
主句漏 will
If you study hard, you pass. If you study hard, you will pass.
第一条件句的主句要用将来时（will/can/may）。

02 第二条件句（虚拟/不太可能）B1 核心 if + 一般过去时, 主句 would/could + 动词原形。与现在事实相反或可能性很小。be 动词一律用 were。 3 条避坑 · 7 题

if + 一般过去时, 主句 would/could + 动词原形。与现在事实相反或可能性很小。be 动词一律用 were。

If + 过去时, 主句 + would + V
  • If I were you, I would accept the offer.如果我是你，我会接受这个提议。（我不是你）
  • If I had more money, I would travel the world.如果我有更多钱，我就去环游世界。（现在没有）
虚拟语气 be 用 was
If I was you, I would go. If I were you, I would go.
第二条件句中 be 动词习惯用 were（尤其在 If I were you 中）。
主句用 will
If I had money, I will buy it. If I had money, I would buy it.
第二条件句主句必须用 would/could/might，不能用 will。
从句用 would
If I would have money, I would buy it. If I had money, I would buy it.
if 从句中不用 would，只用过去时。

03 wish 与 if onlyB1+ 冲卓越 wish + 过去时 = 与现在事实相反的愿望；wish + had done = 对过去的遗憾。 1 条避坑 · 2 题

wish + 过去时 = 与现在事实相反的愿望；wish + had done = 对过去的遗憾。

  • I wish I had a car.我要是有一辆车就好了。（现在没有）
  • I wish I hadn't said that.我真希望我没说那句话。（已经说了）
  • I wish I could fly.我希望能飞。
wish 后用现在时
I wish I have a car. I wish I had a car.
wish 表示与现在事实相反的愿望，从句退一步用过去时。
